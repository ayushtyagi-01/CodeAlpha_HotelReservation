# CodeAlpha Hotel Reservation System

A Java-based Hotel Reservation System developed as part of the CodeAlpha Java Programming Internship.

## Features

- View all hotel rooms
- Search available rooms by category
- Book a room
- View booking details
- Cancel a booking
- Manage customer information
- Track room availability

## Room Categories

- Standard
- Deluxe
- Suite

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Java Collections
